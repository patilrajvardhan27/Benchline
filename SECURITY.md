# Security policy

## Reporting a problem

Email the address on the site's Contact page with the subject "Security", and include enough detail
to reproduce the issue. Please do not access data that is not yours, or disrupt the service, while
testing. You will get an acknowledgement within five working days.

## Supported versions

Only the latest commit on `main`.

## Scope

The web app, the API, and the deployment files in this repository. See [docs/security.md](docs/security.md)
for how the main risks are handled and what is still open.
