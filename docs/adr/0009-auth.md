# 0009. Authentication model

Status: accepted

## Context
Write endpoints and member data need authentication. Running an identity provider is
heavy for local work.

## Decision
The API is a stateless OAuth2 resource server. Production validates tokens from an
OIDC issuer (`OIDC_ISSUER_URI`). Local work validates HS256 tokens signed with
`DEV_JWT_SECRET` (at least 32 bytes). If neither is set, the application refuses to
start, so there is no open mode. The web app signs in with the authorization code flow
and PKCE and keeps the access token in memory only.

## Consequences
No server-side sessions, so nothing to fixate and no CSRF surface. Reloading the page
signs the user out, a deliberate trade for not storing a token.
